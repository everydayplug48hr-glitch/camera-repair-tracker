# Camera Repair Tracker
React + Vite frontend, Supabase backend, deployed on Vercel.

## Run locally
1. `npm install`
2. Copy `.env.example` to `.env` and add your Supabase URL and anon key
3. `npm run dev`

## Deploy
Import the repo in Vercel, add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as environment variables, deploy.
